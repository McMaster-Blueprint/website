# McMaster Blueprint Website

Website for the McMaster Blueprint chapter.

## Getting Started

Install dependencies and run the dev server:

```bash
npm install
npm run dev
```

## Project Structure

- `src/app/` - App Router pages and layout
- `public/logos/` - Blueprint brand logos (standard and negative/dark variants)
- `DESIGN.json` - Design system tokens (colors, typography) for the Blueprint brand
